# Imágenes de la prenda

Coloca aquí las vistas de una misma prenda, idealmente:

- `01-frente.png`
- `02-espalda.png`
- `03-lateral-izquierdo.png`
- `04-lateral-derecho.png`

Se leen en orden alfabético. No subas imágenes con secretos, datos personales
o material que no tengas autorización para usar.
